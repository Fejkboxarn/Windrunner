# Legacy retirement audit

Initial inventory: 283 owned scripts, 1,163 external scripts retained, 2,934 text assets searched. LegacyRetirementInventory.json records every owned script's classification, source mentions, serialized GUID references and retirement condition. CharacterCompositionAudit.json records the loaded scene's enabled/disabled components and profile dependencies before production-only migration. Nothing was deleted during this audit. Source mentions include tooling/comments and cannot alone prove runtime use; dynamic reflection and animation-event methods remain additional removal risks.

The initial audit removed nothing. Production-only lifecycle and ability tests subsequently passed before ten serialized components were retired: PlayerHumanoidAnimatorDriver, PlayerCustomAnimationDriver, PlayerRunningArmPoseController, PlayerProceduralKnifeFlick, PlayerDualThrowPose, PlayerGroundedFootIK, PlayerInputStartupRepair, AirCastFeedback, AirTargetIndicator and AirChargeVisual. RetiredProductionComponents.json lists exact scene IDs and incoming references cleared.

The closed dependency group is now physically retired: those ten runtime classes, seventeen obsolete installers/custom Editors, the previously completed WindrunnerPlaceholderActionSetup, and the detached Batch19_PlayerHumanoid controller, each with its meta. SourceRetirements.json lists every file, pre-removal hashes, GUIDs, callers and reviewed field removals. Every removed script/controller had zero serialized users. The remaining bridge and movement presenter no longer depend on the retired concrete types. ProductionOnlyTests asserts that the retired CLR types are absent and tests automatic graph startup, stop and re-enable. Full suites passed after removal; loaded scene/prefab references are checked in Unity.

The table above records the initial classification; these ten components and their closed tooling group are now **obsolete and removed**, not merely disabled. LegacyRetirementInventory.json is the current inventory (264 owned scripts, 1,163 external scripts, 2,915 text assets at this checkpoint).

Retained with concrete conditions:
- PlayerMovementVisuals remains required for presentation-root bank/lean and jump/land/flip/footstep events. Its unused concrete legacy-driver queries are removed; deleting the presenter requires replacement of these live responsibilities and visual/event-order acceptance.
- Legacy-named animation profile assets/types remain clip-authoring inputs to retained binders/content audits. Remove only after those authoring callers are replaced and their imported clips remain reachable. They do not run a pose graph.
- Input/feedback facade and widget compatibility adapters retain live callers and scene wiring; retirement requires equivalent standalone/optional-widget composition, not a namespace rename.
- Remaining historical tools are inventoried individually. Zero static mentions alone does not prove an Editor menu, reflected method or animation event obsolete; uncertain entries remain until workflow/caller review supports removal.
- Vendor packages, optional FEEL templates, clips, models, sounds, textures, Avatar, node Animator controllers and existing GameObjects/transforms remain. No speculative resource deletion.

Runtime numerical values are unchanged. Automated ownership and behavioral checks are evidence for source retirement, not certification of placeholder pose quality. ProductionOnlyAcceptance.md remains the manual gate for the new automatic animation owner and Studio workflow.
